# Wcześniejsze warianty

Miejsce na wybrane źródła porównań i ablacji: C3-Rule, C3-Meta, C4 oraz
odniesienia N9/N14. Warianty nie zostały przeniesione. Każdy przyszły wpis
powinien wskazywać wersję kodu, protokół, pochodzenie wejść i ograniczenia.
Badania na znanych zbiorach nie są niezależną oceną konkursową.
