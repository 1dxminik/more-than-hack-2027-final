# Dokumentacja do uzupełnienia

Przed udostępnieniem tej alternatywnej metody należy:

1. Przenieść minimalny kod i dokładną konfigurację C5-alpha-0.1 z przypiętej wersji.
2. Ustalić licencję własnego kodu oraz zachować licencje i pochodzenie komponentów.
3. Opisać pochodzenie danych treningowych i zasobów oraz legalny dostęp do wag.
4. Przypiąć zależności i podać działającą instrukcję instalacji oraz reprodukcji.
5. Opisać wyniki, regresje i ograniczenia porównań na znanych meczach IDSSE.
6. Wyraźnie oddzielić C5 jako alternatywę od głównego rozwiązania zgłoszeniowego.
7. Sprawdzić kod na syntetyce oraz przejrzeć pliki przeznaczone do publikacji.

Nie deklarujemy wykonania tych czynności na podstawie samego szkieletu.
