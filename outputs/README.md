# Lokalne wyniki

Katalog nie zawiera predykcji ani raportów wykonania. Wyniki, logi, cache
i pliki zgłoszenia pozostają poza historią Git.

Przyszły eksporter C5 ma zapisywać wynik w jawnym, nowym katalogu prywatnym
wybranym przez operatora. Nie zakładamy, że zapisze go w tym `outputs/`.
Nie kierujemy inferencji na wyniki kolegi i nie zastępujemy jego CSV.

CSV C5 nie jest dodatkowym plikiem do obecnego zgłoszenia. Zgodnie
z informacją użytkownika formularzem wysłano już CSV metody kolegi.
Kontrola formatu C5 nie zastępuje sprawdzenia jego własnej reprodukcji.
