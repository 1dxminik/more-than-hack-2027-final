# Wyniki lokalne

`synthetic-c5/<run>/` zawiera dwa świeże syntetyczne CSV i odbiór techniczny.
To nie pliki konkursowe. Finalny eksporter zapisuje dokładnie w `--out`.
Konkursowych CSV, cache, logów i raportów nie dodajemy do historii Git.
Gałąź nie zawiera ani nie zastępuje pliku zgłoszonego przez kolegę.
