# Local outputs

The final `Ctrl_Alt_Elite.csv` is generated by `scripts.predict_tcn` at the path
specified by `--out`. The main [README](../README.md#reproduce-the-submission)
uses an external directory for the private output. The exporter does not
automatically select this `outputs/` directory; the filename also comes from
`--out`.

The submission CSV is uploaded separately through the submission form. It must
not be added to public Git or sent to AI services. Format validation does not
replace comparison with the reference CSV SHA-256 given in the main README.

`synthetic/` is generated by `./run.ps1 demo`:

- `submissions/`: four CSVs generated by the official baseline;
- `evaluation/scoreboard.csv`: scores on synthetic data;
- `evaluation/reports/`: reports from the official scorer;
- `logs/`: full output from the unchanged baseline and scorer;
- `run_manifest.json`: environment versions, source provenance and output hashes.

These are demonstration files. Do not submit them as the competition solution.
Synthetic scores do not establish performance on a real match. Statistical
uncertainty comments in the original scorer log refer to its calibration on
the real match and must not be transferred to this synthetic demonstration.

Everything in this directory except this README is excluded from Git.

`synthetic-step1/` is generated by `./run.ps1 improve`. It has analogous
subdirectories and **seven CSVs**: the four official baselines,
`step1_memory_dead.csv`, `step1_filled.csv` and `segment_decoder.csv`.
`comparison.json` reports errors by synthetic scenario, including deliberately
difficult cases. `run_manifest.json` records method parameters and source hashes.
Compare results only within the same input dataset.

`tcn/v1/` is generated by the optional `scripts.train_tcn cv --run v1` command.
It contains newly trained models, configuration, fold reports, scores and logs.
The final exporter defaults to the published weights in `weights/tcn_v1/`;
it does not automatically use models from `outputs/tcn/v1/`. Retraining is not
needed to reproduce the submission and does not guarantee identical weights.
