# Indeks artefaktów

Miejsce na spis wersji kodu, konfiguracji i odsyłaczy do zasobów dopuszczonych
do udostępnienia. Katalog nie zawiera jeszcze artefaktów.

pozostają poza historią Git. Ten indeks nie stanowi zgody na ich publikację.
