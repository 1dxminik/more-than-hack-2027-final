# Wsparcie wykonania

Miejsce na eksporter C5, kontrolę kompletnego zestawu zasobów i ich SHA-256,
oficjalną walidację oraz sprawdzenie dwóch świeżych procesów.
Skryptów wykonawczych jeszcze nie przeniesiono. `scripts.predict_tcn` kolegi
nie uruchamia C5 i nie jest jego poleceniem reprodukcji.

Nie dodajemy domyślnych prywatnych ścieżek ani automatycznego pobierania danych.
Instalacja i składnia poleceń nie zastępują odbioru inferencji oraz finalnego CSV.
