# Lokalne wejścia

Katalog nie zawiera danych. Wejścia pozostają poza historią Git.

Po przeniesieniu kodu przyszłe demo i improve mają korzystać wyłącznie
z syntetyki. Finalny operator przechowuje pakiet poza repo i jawnie wskazuje
katalog całego pakietu, zawierający `tactical/`, oraz właściwe XML i TXT.
Nie zgadujemy zachowania `MTAH_DATA_DIR` z eksportera kolegi; kontrakt
nowej ścieżki C5 wymaga sprawdzenia podczas przeniesienia.

Nie kopiujemy danych konkursowych do tego szkieletu ani do usług AI.
