# Input data

This directory is used for the synthetic checks described below. The final TCN
method needs two files: the **tactical ATD** metadata XML and raw tracking TXT.
An authorised operator keeps the competition bundle outside the public repository
and supplies explicit paths through `--atd-xml` and `--atd-raw`. In the main
[README example](../README.md#reproduce-the-submission), `dataDir` is the root
of the unpacked bundle, containing the `tactical/` subdirectory.

The `scripts.predict_tcn` exporter does not use `MTAH_DATA_DIR`. It does not need
video, Smart Tagging, homography or ground truth. Competition data and private
execution outputs must not be sent to AI services.

`synthetic/` is generated by `./run.ps1 demo`. It contains only invented tracking,
the minimal metadata needed by the baseline and synthetic reference labels.
It is not a complete EPTS export for testing kloppy and does not contain video.

Do not place private competition data here. The demo does not need videos,
Smart Tagging, homography, Drive access or public ground truth.

Everything in this directory except this README is excluded from Git.

`synthetic-step1/` is generated by `./run.ps1 improve`. It contains a separate set
of invented scenarios: ball occlusions, stoppages, restarts, missing players and
ambiguous cases. `synthetic_cases.json` is used only for evaluation after
predictions have been generated; it is not an algorithm input. The earlier
`synthetic/` dataset is kept separate.
